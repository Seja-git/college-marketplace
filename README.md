
# CampusCart AI 🛒

**CampusCart AI** is a full-stack college marketplace platform that enables students to buy and sell second-hand products securely within their college community. The application focuses on providing a seamless, organized, and trusted marketplace experience while laying the foundation for intelligent AI-powered features.

---

## 🚀 Features

### User Authentication
- Secure user registration and login
- Password hashing for enhanced security
- Session-based authentication
- User profile management

### Marketplace
- Create, edit, and delete product listings
- Upload product images
- Browse products with responsive product cards
- View detailed product information
- Mark products as sold

### Search & Filtering
- Search products by title
- Filter products by category
- Filter products by price range

### Buyer-Seller Interaction
- Real-time buyer-seller conversations
- Dedicated messaging interface
- Personalized conversation history

### Wishlist
- Save favorite products
- Add and remove items from wishlist
- View saved products anytime

### Dashboard
- View personal listings
- Manage posted products
- Access wishlist
- Track conversations

## ⚙ Installation

Clone the repository

```bash
git clone :  https://github.com/Seja-git/college-marketplace.git
```

Navigate to the project directory

```bash
cd CampusCart-AI
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
